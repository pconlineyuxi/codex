# AI 调用受限提示

用户要求：AI 额度受限时在工具中明确提醒。覆盖业务问题解析，以及查询、手动巡查和利润对比后的数据问答。

解析与问答共用允许列表中的错误分类，区分额度耗尽、频率限制、认证/模型权限、网络/超时和无效响应。仅展示固定中文说明，不暴露服务商错误正文、密钥或请求数据。

实际调用失败后，在当前会话页面顶部保留提醒；额度问题附 OpenAI API 账单入口，说明需为 Key 所属组织充值。切换工作区仍可看到最近反馈，下一次成功的 AI 调用清除提示。首次打开不额外调用 API 检查余额，不把未测试状态判为可用。

解析失败仍返回明确标识的本地规则草稿；问答失败不追加假回答、不清空已有对话或结果。人工查询、规则巡查和利润计算保持现有行为。数据、规则、SQL 和巡查语义版本不变。

验收：模拟额度不足与普通 429，检查所有入口提示与链接；验证页面重绘和工作区切换保留提示，重试成功清除，失败保留结果与历史，错误输出不含秘密文本；运行现有回归测试。
