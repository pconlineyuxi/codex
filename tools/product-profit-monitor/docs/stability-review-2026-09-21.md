# Product Profit 稳定性修正（2026-09-21）

范围：落实本次功能审查，不增加业务工作区，不启用真实自动巡查或通知。

## 已批准的修正与验收

- 原始 promotion 单独保留为 raw_promotion。负值规则只检查原始符号并提示待核查；促销成本继续使用 ABS，销售额继续扣促销。缺失原始字段不得判定规则通过。
- 日期或选项变化保留已选平台和店铺；不在当前选项中的选择仍作为筛选生效并显示提示，只有用户清空才扩大范围。
- 查询失败保留上次成功结果并标记，禁用旧结果问答；成功重查后恢复。手动巡查和查询均显示逐日读取进度。
- 解释手动巡查、业务查询与计划巡查的结果归属：前两者在各自页面继续提问，后者写入异常状态历史。浏览器会话结束后不承诺保留源数据对话。
- 真实查询默认累计不超过 500000 行、源 DataFrame 估算 256 MiB。超过即失败，不返回部分结果。两期比较分别受限；此值不是整个 Python 进程内存上限，统计和复制仍有额外开销。
- 每次 AI 回答使用独立证据编号，拒绝无源证据引用、引用不存在编号及被截断的回答。此检查校验证据关联，不证明所有自然语言数值或因果推断正确。
- 规则版本覆盖诊断 YAML、筛选映射、SQL/检测/服务/数据库代码；旧会话结果在版本变化后清除，计划范围版本也随之变化。

## 验证方法与边界

运行全套 pytest，另以 Streamlit AppTest 回归日期/平台切换、查询失败及重试；模拟数据验证促销符号、累计上限、引用与截断检查、版本变更。
真实币种、时区、刷新完整性仍需业务与数据源确认。未因本轮修正启用正式计划或发送通知。
